How it works

  1. Upload a .docx article. Its headings, paragraphs, bullet lists and tables are extracted as separate blocks.
  2. On the next screen, assign each block to a field — module title, overview, audience, or a topic's title / summary / items.
  3. Preview the module that will be created, then apply it. Bold, italics and links in paragraphs are kept as Markdown.

Embedded images are ignored. Nested lists are flattened to a single level.
